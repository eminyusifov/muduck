# Muduck: ход работ

## 2026-10-09: аудит, исправления, оптимизация, версия для Windows

### Исправлено
- **Безопасность.** Документ (вывод ИИ) мог выполнить JS через сырой HTML, `onerror`, mermaid `securityLevel: loose`, `javascript:` ссылки или язык code-блока, а дальше вызвать `save_file` с любым путём. Теперь: DOMPurify (`FORBID_ATTR: name`, `SANITIZE_DOM: false` ради id заголовков), строгий CSP в `tauri.conf.json`, mermaid `strict`, обработчики кнопок через делегирование вместо inline `onclick`.
- **Окно не перетаскивалось и не разворачивалось:** в capabilities не было `core:window:allow-start-dragging` / `allow-toggle-maximize`. Класса `pl-18` нет в Tailwind 3, поэтому кнопки стояли под «светофором». Теперь `pl-[72px]`, только на macOS.
- **Потеря данных.**
  - Внешняя запись в файл затирала несохранённые правки.
  - Событие от старого файла могло записаться в новый.
  - Открытие или закрытие окна (и Cmd+Q) шло без вопроса о несохранённых правках.
  - Cmd+S в редакторе срабатывал дважды.
- **Рендер.**
  - `$` внутри кода превращался в формулу, а «$5 and $10» в математику.
  - Тела callout'ов рендерились до настройки renderer.
  - Чекбоксы задач дублировались.
  - Оглавление расходилось с id заголовков: `&`, апостроф, юникод, `#` в коде, дубликаты.
  - Вложенные `<a>`.
- **Вотчер.** Сравнивает `(mtime, size)` вместо одного `mtime >`. Файл читается только после двух одинаковых опросов подряд, без удержания блокировки. Свои сохранения не возвращаются эхом.
- **Мелочи.**
  - Ссылки не открывались: добавлен opener; относительные `.md` открываются в приложении.
  - Поиск ломал SVG диаграмм.
  - Синхронизация скролла теряла события.
  - Таймер тоста; утечки слушателей в StrictMode.
  - Устаревший `pending_file`.

### Оптимизация
- Основной JS-бандл уменьшен с 1727 до 705 КБ: mermaid подгружается лениво, `highlight.js/lib/common` вместо полной сборки.
- Документ парсится один раз (html + оглавление) через `useDeferredValue`. SVG mermaid кэшируются, диаграммы рендерятся по одной. `highlightAuto` идёт только по 12 языкам.

### Windows
- Кросс-компиляция с Mac: `cargo-xwin` + NSIS (команды в CLAUDE.md). Установщик ставится на текущего пользователя, WebView2 подтягивается при необходимости.
- Плагин single-instance: второй запуск с файлом открывает его в уже запущенном окне.
- `dunce` для путей без `\\?\`. `RunEvent::Opened` закрыт `#[cfg]` под macOS.
- Ассоциация с `.txt` убрана, чтобы установщик не забирал все текстовые файлы.

### Проверено
- `tsc` и `cargo check` проходят на macOS; `cargo xwin check` проходит для Windows.
- Headless Chrome под тем же CSP: XSS не выполняется, нарушений CSP нет, формулы, диаграммы, callout'ы и поиск работают.
- Собранная `Muduck.app`: файл открывается из аргумента, внешняя правка подхватывается («Updated externally», оглавление обновилось).

### Не проверено / открыто
- Windows-сборка не запускалась на настоящем Windows: проверены только компиляция и сборка установщика.
- `window.print()` (экспорт в PDF) в WKWebView и WebView2 не проверялся.
- Локальные картинки по относительным путям не показываются: нужен asset protocol, не делалось.
- Устаревший Electron-код (`src/main`, `electron-builder.json`) не трогали.

## 2026-10-09: Quick Look (пробел в Finder)
- Расширение `src-tauri/quicklook` (Swift, WKWebView) показывает страницу `src/quicklook` на том же парсере, что и приложение: темы, KaTeX, подсветка кода, callout'ы, mermaid. Тема следует системной светлой или тёмной.
- Встраивается в `Muduck.app` автоматически при `tauri build` (`beforeBundleCommand` + `bundle.macOS.files` + ad-hoc подпись). Сборка для Windows не затронута.
- Проверено в настоящем `qlmanage -p` из `/Applications/Muduck.app`: текст, формулы, диаграмма, код, callout.
- На машине был QLMarkdown, который перехватывал Markdown. По решению владельца его Quick Look-расширение отключено (`pluginkit -e ignore -i org.sbarex.QLMarkdown.QLExtension`; вернуть: `-e use`). Само приложение QLMarkdown не удалено.
- Новая сборка установлена в `/Applications` (старая версия заменена).
- Windows: аналог возможен как обработчик превью Проводника (Alt+P, COM + WebView2, страница превью общая). Не делалось, проверить можно только на настоящем Windows.
